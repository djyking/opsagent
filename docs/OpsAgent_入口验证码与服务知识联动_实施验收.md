# OpsAgent 入口、验证码与服务知识联动

本轮保留现有登录动效和系统内页风格，修正操作入口行为，补充登录校验，并让问答使用真实服务目录和有权访问的工单附件。

## 操作入口

- 输入匹配到能力后，右侧按钮显示“打开入口”，点击与 Enter 使用同一处理逻辑，打开当前高亮或首个匹配项。
- 空输入显示“浏览入口”；没有匹配时显示“查看候选”，由用户明确选择候选操作。
- 保留方向键选择、Esc 关闭以及中文输入法组合期间不跳转的行为。
- 问答入口仍只携带草稿，不自动发送提问。

## 登录验证码

- 新增 `GET /api/auth/captcha`，返回随机五位 PNG 图片、随机 `captchaId` 和 `expiresInSeconds=120`，不返回答案。
- `POST /api/auth/login` 增加必填 `captchaId`、`captchaCode`。大小写不敏感，Redis 保存摘要并原子消费；错误、过期或重放均拒绝。密码错误也需要重新获取验证码。
- 页面支持点击图片或“换一张”刷新，显示加载失败和过期状态，登录失败自动换图；保留原有动态介绍和整体布局。
- 发放接口按连接来源和全局限制频率。经网关转发时，同一网关来源共享额度；生产多用户部署可按实际流量调整配置。
- 注册和 refresh 协议保持现有行为。脚本使用现有有效 Token，或由操作者提供新获取的验证码参数；没有绕过验证码的生产接口。

## 服务目录与问答

- 明确询问当前服务清单、组件清单和依赖登记时，从平台 CMDB 接口读取真实记录并生成结构化表格，不依赖上传一份易过期的服务清单。
- 只读取回答需要的目录字段；不在回答中列出连接密码或管理端点。
- 引用标记为 `CMDB`，显示本次读取时间，提供“查看服务目录与关系”链接。目录登记状态与系统监控健康状态区分展示。
- CMDB 引用与文档引用共用完整 SSE / 会话持久化链路；目录读取失败时明确显示失败，不伪造服务清单。
- 选中具体文档时，该范围优先于目录意图；回答仅依据所选文档。工单默认模式可识别目录问题，其他问题检索本工单附件，并验证工单访问权限。

## 工单附件检索

- 工单页面将 `ticketId` 传递到普通和流式问答接口，再传递到知识服务。
- 显式文档 / 工单范围读取已解析、可访问的数据库切片，支持拥有者和管理员预览未发布草稿；不会将草稿发布到全局知识索引。
- 同时传入 `documentId`、`ticketId` 时取交集；无权、已删除、未解析或不属于本工单的文档不会回退到其他资料。
- 全局知识检索继续使用现有检索、向量和重排流程。

## 品牌与运行数据

- 将现有演示文档、生成器、初始化数据和实际知识内容中的旧品牌统一为 OpsAgent，并同步真实检索索引。
- 保留原文档和切片 ID、业务关系和历史记录。迁移原件及本地配置备份位于 Git 忽略目录。
- 修复 Docker 知识服务未加载原有 Embedding 配置的问题，沿用 OpenAI `text-embedding-3-small`，密钥仅存于被忽略的本地配置。
- 修复 Elasticsearch Bulk 使用字符串 NDJSON 时默认编码导致中文变为问号的问题：明确使用 UTF-8 请求头和字节数组。根据完好的数据库 / Qdrant 正文定向恢复索引，并逐字符验证全部正文和文档名。
- 已删除的用户文档保持删除；失效或删除文档的旧索引任务停止重试。
