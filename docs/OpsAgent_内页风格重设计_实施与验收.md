# OpsAgent 内页风格重设计：实施与验收

日期：2026-09-05

## 完成结果

以用户认可的登录页为视觉基准，先完成《OpsAgent_登录风格延展_内页设计方案》，再实施公共框架和各业务页面。新版前端已构建并更新到 http://127.0.0.1:5173，前端容器健康检查通过，正式端口的真实登录与运行总览数据读取通过。

源代码位于 `D:\myselfProject\opsagent\ops-web`。本轮主要修改前端展示与相关交互，使用现有后端接口、鉴权和业务数据。原有登录页继续作为视觉基准；业务页面采用静态内容布局，保留必要的交互反馈。

## 设计与公共组件

- 统一浅蓝画布、少量浅青点缀、白色圆角卡片、蓝灰文字、细边框和柔和阴影。
- 在 `tokens.css` 定义内页主题，在各自所属的基础样式和页面样式中实现；没有在 `main.css` 末尾叠加整站覆盖。内页主题同时覆盖挂载到 body 的弹窗。
- 统一页首图标、标题、说明、操作区，以及指标卡、表格、筛选器、输入框和弹层的几何与间距。
- 将原图标轨道和变化的二级导航合并为稳定的分组侧栏：工作台、运维协作、AI 与知识、系统管理。桌面支持 240px 展开和 76px 收起，900px 以下使用抽屉导航；按账号角色显示入口。
- 顶栏统一当前位置、工单搜索、创建和通知入口，服务监控入口通往真实监控页面。
- 补齐移动导航的焦点管理、Esc 关闭、关闭后焦点恢复，以及切回桌面时解除主区不可交互状态。

## 页面改动

| 页面 | 本轮调整 |

| 工单中心 | 统一统计、筛选和列表卡片；表格横向滚动局限于容器；修复停留在本页时顶部搜索不更新结果的问题 |
| 工单详情 / 结构化处置 | 统一身份区与页签，活动时间线使用主区，关联记录放在辅助区，改善处置表单层次 |
| 活动告警 | 真实告警摘要卡、清晰的风险颜色和记录表格 |
| SLA 看板 | 指标卡按实际数量排布，避免第五张卡孤立换行，统一风险列表 |

| 系统监控 | 真实采集概况、四张指标卡、采集目标表和 Prometheus/Grafana 入口；区分端点采集状态与业务健康 |
| AI 能力中心 | 静态能力介绍、任务入口与能力卡，延续登录页的浅色图形语言 |
| 智能问答 | 重排会话列表、欢迎态、回答、引用和输入区，调整桌面高度与移动端布局 |
| 知识库 | 统一知识库目录、文档主区、上传入口、数量和状态表达 |
| 知识审核 / 索引管理 | 审核步骤、统计与记录层次统一；索引未知状态显示检查中或不可用，避免误显示零或一致 |
| 通知中心 / 操作审计 | 未读信息分组、统一筛选与记录表面，改善详情层次和表格滚动 |
| 注册 / UI 基础页 | 注册采用同源静态品牌面板与真实注册表单；基础页更新为主题、控件、状态、表格和弹层样本 |

公共交互同步修复：创建菜单在路由变化后关闭；工单创建参数使用后清理，支持再次打开；恢复文件拖入反馈；触屏下直接显示原先依赖行悬停的操作。
