# 运行总览与能力搜索：设计及验收

## 设计方案（先设计、后实现）

本轮将运行总览定位为「可开始工作、可了解当前态势」的工作台。保留已认可的浅蓝与薄荷色背景、白色圆角卡片、统一字体及侧栏层级；不修改登录页，不增加自动轮播。

### 页面层次

1. 页头保留运行总览名称、同步状态和手动刷新。
2. 欢迎工作区展示账号称呼、日期与「今天想处理什么？」目标输入，提供创建工单、排查问题、查看值班等快捷入口。采用轻量图形与柔和底色，不占用过多首屏高度。
3. 核心指标继续来自工单、SLA、告警及值班接口；未获取的数据用未知状态表示，不把失败当作零风险。
4. 活跃工单区提供全部活跃、高优先级、待确认切换；右侧展示当前风险、当班人员与后续入口。下方保留服务健康、工单分布和最近更新。
5. 1920/1440 为主要验收尺寸；窄屏内容按顺序堆叠，表格使用自身横向滚动，页面不横向溢出。

### 操作与能力搜索

增加搜索有实际价值：既支持已知功能名（值班、拓扑、知识库），也支持工作目标（排查 Redis、创建工单、查询 SLA）。使用本地功能目录、关键词及同义词匹配，明确展示匹配入口，不称为大模型推理，也不伪造匹配置信度。

- 搜索目录覆盖真实已存在的工单、监控、SLA、值班、CMDB、智能问答、知识治理功能。
- 按当前账号权限过滤管理员入口；路由守卫与后端鉴权保持有效。
- 支持输入、快捷词、键盘选择、回车打开、Escape 关闭结果。
- 点击结果只导航。创建工单打开现有表单；问答目标进入新会话草稿，不自动提交，也不覆盖历史会话。
- 无匹配时明确提示，可用原关键词查工单或转入问答草稿。顶部现有工单搜索保持有效。
- 数据与匹配逻辑集中维护，组件局部样式归属明确，不在 main.css 末尾追加覆盖层。

### 班次分页

- 班次管理使用后端分页，默认每页 10 条，可选择 20/50 条，显示总数与当前页。
- 支持按值班计划筛选；筛选及页容量变化回到第一页，删除最后一条时回退有效页。
- 日历使用独立的日期区间查询，包含跨日、跨区间的有效班次；分页不改变当前值班或七天日历。
- 保持原有新增、编辑、删除及管理员权限。新增分页接口兼容已有调用。

## 验收计划

- 前端类型检查、生产构建、搜索匹配与权限/导航测试。
- 班次分页、边界及日期区间后端测试，并运行项目要求的 Maven clean verify。
- 更新本地 5173 所需服务，验证搜索真实跳转、问答草稿与历史保留、班次翻页和日历。
- 在 1920、1440 及窄屏检查布局；截图、临时验证脚本与日志保存在 Git 已忽略的 ui-experience-final 下。

## 实施与验证结果

### 已实施

1. **工作台入口重设计**：增加账号问候、日期、轻量知识/协作示意，以及「今天想处理什么」目标输入。维持浅蓝/薄荷色、白色圆角卡片与现有导航；移除内容重复的旧重点介绍面板。
2. **操作与能力搜索**：集中维护 13 个真实功能入口，支持功能名、常用目标、同义词、中文/英文大小写及快捷词；支持上下键选择、Enter 打开、Escape 关闭和中文输入法候选键保护。普通账号不会看到管理员入口。无匹配时提供工单关键词查询和问答草稿入口。
3. **真实流程交接**：「创建工单」打开现有表单；「查询工单」等纯功能词进入列表，不作为业务关键词误筛选；「搜索工单 Redis」传递 Redis；「排查 Redis」传递原始问题至新会话草稿，不自动发送。既有会话继续按账号保留。修复查询参数消费、慢请求覆盖草稿及离开问答页时改写目标页面参数的竞态。
4. **运行态势整理**：指标下方保留重点工单、风险与当班人员。工单区增加全部活跃/高优先级/待确认切换，明确显示当前总量及前 7 项。下方保留服务健康、全部八种工单状态和最近更新。
5. **统计准确性**：总览读取后端当前账号可见的完整工单列表，取消前端 100 条截断；最近活动按更新时间排序；处理中只计 PROCESSING；SLA 风险与风险页口径一致，另列已超时 SLA。首次数据失败显示未获取，刷新失败保留并标注上次结果，不用旧的零值表示当前无风险。
6. **班次管理分页**：新建 `/api/platform/oncall/shifts/page`，默认 10 条，支持 20/50 条、计划筛选、准确计数及超范围页码回退。管理口径为当前及未来班次，保留停用计划供维护。
7. **独立日历与值班**：新建 `/api/platform/oncall/shifts/calendar`，按半开日期区间查询已启用计划的所有交集班次，包含跨日班次及同一天同角色多个班次。日历不受管理页分页影响。当前值班统一为全部计划的有效人员，页面明确其范围。

### 修改位置

- 前端：`WorkspaceLauncher.vue`、`workspace-actions.ts`、`DashboardView.vue`、`dashboard.css`、`OnCallView.vue`、`oncall.css`、班次 API、RAG 会话 composable 与页面、`rag-navigation.ts`。
- 后端：平台服务 `ItsmPlatformController/Service/Repository`、新增 `OnCallShiftDtos`。沿用既有数据库表，不需要新增生产依赖或数据库迁移；H2 仅用于 SQL 测试。
- 测试：`OnCallShiftPaginationTest`、`workspace-actions.test.mjs`、`rag-navigation.test.mjs`、`dashboard-data.test.mjs`，以及 npm `test:workspace` 脚本。
