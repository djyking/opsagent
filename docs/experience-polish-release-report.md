日期：2026-09-06。状态：已部署，构建、组件与公网接口验收通过。访问：https://opsagent.cloud 。

## 设计

保留现有蓝白视觉和 Spring Cloud 服务架构。本轮围绕可阅读、可审核、可操作改进：公共控件统一字体和几何；轨迹按真实节点折叠；审批采用全站入口、一次性新事项提醒和明确动作说明；知识审核先阅读正文再决定。

知识库优先仍保留，新增的是只读官方文档联网补充工具，并非只删除 Prompt 或允许任意命令。工具只接收固定技术主题及知识不足类型，访问已核验的 Redis、Nacos、Sentinel、RabbitMQ 官方来源；不把工单正文和内部文件发送给搜索网站。外部内容必须标注来源与获取时间，不能改变执行权限或替代目标恢复验证。

## 已确认根因与修复

- 服务目录：新增隔离目标迁移未声明 MySQL 客户端字符集，中文 UTF-8 被按另一字符集写入。修复三个配置项的名称/说明及三条依赖说明，共九个值，使用内容 hash 条件保护后来编辑的数据。原迁移增加 `SET NAMES utf8mb4`；增量修复脚本可重复执行。
- 字体与控件：系统内明确中文无衬线字体回退，输入值和占位字重归一，正文行高一致；焦点保留单一边框与阴影，去掉重复轮廓。保留登录页原字体合同。
- AI 自动化：运行表单、筛选栏和节点卡片校准字号、基线与留白；两类演练按钮使用同一主按钮样式。
- 执行轨迹：按真实节点分组为可展开父级，原始参数和证据进一步折叠；节点内按事件 ID 保留原始时序，阶段只做计数摘要。没有节点 ID 的事件单列为运行控制记录。
- 审批：全局待审批入口和数量，新审批一次提醒，允许稍后处理；页面内外共用中文审批卡片，展示目标、预期变化、影响范围和有效期，JSON放到技术详情。实际审批仍绑定精确版本与参数摘要。访客访问策略同步放行这一精确 GET 路径，服务层继续按本人运行过滤；其他方法、未知路径和目录仍拒绝。
- 知识审核：受保护的文档正文/切片分页预览和源文件下载；内容尚未加载或不可读时不给出盲审成功入口。
- 工单：问答、结构化处置输入和证据区迁移到统一控件和表单Surface，保留实际提交逻辑。
