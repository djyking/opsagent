## 主节点故障

Redis 主节点故障后，应首先确认 Sentinel 是否完成主从切换。确认新的主节点已经产生后，再检查应用连接是否刷新、复制积压是否恢复，以及旧主节点是否被安全隔离。

在没有确认主从角色和数据一致性前，不要直接重启全部 Redis 实例。操作前应记录当前拓扑与告警时间；操作后验证写入、读取和复制延迟；若切换异常，按变更记录回滚客户端路由并升级处置。
